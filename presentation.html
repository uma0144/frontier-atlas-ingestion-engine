Core Technical Architecture

🕷️ 1. Asynchronous Crawlers

Built with non-blocking aiohttp, TCP connection pooling, semaphore rate controls, and randomized User-Agent rotation for massive concurrent scraping.

🤖 2. Multi-Tier LLM Cascade

Automated failover: Gemini 2.0 Flash → Groq LLaMA 3.3 70B → Deterministic Extractor. Eliminates downtime and upstream provider failures.

🛡️ 3. Anti-413 & Anti-429 Resilience

Anti-413: Semantic DOM pruning strips non-content tags.
Anti-429: Token Bucket rate limiters + exponential backoff with random jitter.

🔍 4. Deterministic Entity Resolution

Strips corporate suffixes (Inc, LLC, Corp, PBC, GmbH) and applies RapidFuzz token sorting (≥85%) against 50+ canonical seed organizations.
